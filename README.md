# 🐧 Linux Learning Journey

A structured collection of Linux command-line notes, examples, and exercises — covering everything from basics to advanced text processing.

## 📂 What's Inside

| Topic | Description |
|---|---|
| `Find Command` | Basic find usage — locating files and directories |
| `Find Name & Type` | Searching by filename and file type |
| `Find Size & Time` | Filtering files by size and modification time |
| `Find Owner & Group` | Ownership-based file searching |
| `Find Permission Search` | Finding files by permission bits |
| `awk` | Introduction to awk for text processing |
| `awk cheat sheet` | Quick reference for awk patterns and actions |
| `conditions in awk` | if/else and pattern matching in awk |
| `loop in awk` | for/while loops in awk |
| `variables in awk` | Built-in and user-defined awk variables |
| `Text Processing` | grep, sed, cut, sort, uniq, wc commands |
| `User & Group Management` | useradd, usermod, groupadd, passwd |
| `Variables` | Shell variables, env vars, export |
| `File Permissions` | chmod, chown, umask, SUID/SGID |
| `Redirections` | stdin, stdout, stderr, pipes |

## 🧠 Key Concepts Covered

- File system navigation and management
- Text processing with awk, sed, grep
- File permissions and ownership
- User and group administration
- Shell variables and redirections
- Find command with all major flags

## 🚀 How to Use

Clone the repo and explore each file:

```bash
git clone https://github.com/Khade-Dinesh/LINUX-Learning.git

```
